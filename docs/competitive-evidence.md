# Доказательность конкурентных утверждений

## Текущее положение

IntegrityGuard разрабатывается для контроля целостности пакетно-нейросетевых
программ, подтверждения происхождения артефактов, объяснимого сравнения
изменений и автоматической обработки поступающих файлов. Это целевые функции
проекта и требования из его ТЗ; они сами по себе не доказывают превосходство
над другими продуктами.

В `ui-design.md` Wazuh, Elastic Security и Microsoft Defender используются
как источники отдельных UI-паттернов. Этот документ не содержит измерений
полноты обнаружения, точности, времени обработки или стоимости в сравнении с
IntegrityGuard. Проверенного функционального benchmark для Wazuh, AIDE, AIRS,
Elastic Security или Microsoft Defender в проекте сейчас нет. Указание AIRS
не привязано в имеющихся материалах к конкретному поставщику и версии.

Поэтому помощник не должен отвечать, что IntegrityGuard «лучше» конкретного
конкурента, или приписывать конкуренту/IntegrityGuard функциональность, которую
не подтверждает источник. Допустимый ответ: назвать документированные цели и
реализованные функции IntegrityGuard, явно отметить отсутствие прямой
сравнительной оценки и перечислить необходимые условия для такой оценки.

## Условия будущего сравнения

Сравнение допустимо после фиксации точных продуктов, редакций и версий,
области использования, одинакового набора реальных подтверждённых сценариев,
аппаратного окружения и заранее согласованных метрик. Результат должен
показывать исходные измерения, пропуски, неопределённость и ограничения;
маркетинговые описания и синтетические демонстрационные пакеты не являются
доказательством превосходства.
