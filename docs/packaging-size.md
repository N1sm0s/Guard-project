интерфейс и пользовательские данные сохранены.

Предыдущая сборка уже использовала CPU-only PyTorch и исключала часть Qt.
Поэтому дополнительная безопасная очистка дала небольшой эффект.
Размер относится ко всей установленной папке, а не только EXE.
Резервная копия и промежуточные файлы в build не входят в этот размер.

В IntegrityGuard.spec явно выбран matplotlib Agg для PNG-графиков.
Исключены developer-only модули pytest, IPython, notebook, sphinx,
torch.utils.benchmark, torch.utils.bottleneck, matplotlib.testing и numpy.f2py.
Часть из них и раньше отсутствовала; явные исключения предотвращают их
случайное включение при изменении окружения.

PATH при сборке ограничен каталогами Python и Windows. Без этого первая
пробная сборка подхватила DLL из Codex/Poppler/libheif и выросла на 41,61 МиБ.
Исправление делает поиск библиотек независимым от этих внешних каталогов.
Сохранены прежние меры против конфликтов Qt DLL.
