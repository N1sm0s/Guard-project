# Дообучение локального помощника

## Решение по инструменту

Для эксперимента выбрана цепочка **Unsloth + QLoRA/SFT + экспорт GGUF + Ollama**.
Unsloth предоставляет локальное дообучение и документирует Windows; Ollama
запускает импортированную модель, а IntegrityGuard обращается к её loopback API.
Ollama сама не обучает веса модели: она создаёт и запускает пользовательские
сборки через `Modelfile`, в том числе из GGUF. Подробности импорта см. в
[официальной инструкции Ollama](https://docs.ollama.com/import) и
[справочнике Modelfile](https://docs.ollama.com/modelfile).

Выбранный тип задачи — QLoRA supervised fine-tuning (SFT), чтобы научить модель
формату ответов о сетевой телеметрии IntegrityGuard и безопасному использованию
ограниченных read-only инструментов. Источником фактов служат текущие измерения
и проверяемое состояние приложения; ответы по ТЗ, индексирование файлов,
цитирование документов и RAG в продукт не входят. Формат SFT требует
проверенных пар «наблюдения — целевой ответ»; случайные или синтетические
примеры не являются таким набором. [Руководство TRL SFT](https://huggingface.co/docs/trl/sft_trainer)
описывает разговорный набор и обучение только на сообщениях ассистента.

## Проверенные условия этого компьютера

- CPU: Intel Core i9-12900F, 16 ядер / 24 потока.
- RAM: 32 GiB всего; на момент проверки свободно около 10 GiB.
- GPU: NVIDIA RTX 3080 Ti, 12 GiB VRAM; CUDA доступна в рабочем Python.
- На GPU во время проверки было свободно около 9.1 GiB.
- Ollama 0.40.16 установлена в пользовательский профиль; локальная модель
  `qwen3.5:4b` (Q4_K_M, около 3.3 GB) доступна на loopback API. Файлы весов
  хранятся отдельно от приложения в `F:\OllamaModels`.
- В репозитории нет подтверждённого набора SFT для помощника. Найденные `.pt`
  корпуса относятся к существующему детектору и помечены в методике как
  синтетические; использовать их для обучения LLM нельзя.
- Подтверждённого набора реальных сетевых событий и экспертных целевых решений
  для SFT пока нет. Обучение не запускается до появления таких данных.

Unsloth указывает нижние ориентиры QLoRA VRAM около 3.5 GiB для 3B и 5 GiB для
7B моделей; это минимальные оценки, фактическая память зависит от модели,
контекста и batch size. Поэтому первый кандидат после появления корпуса —
3B–4B, batch size 1 и короткий контекст; окончательный выбор только после
проверки памяти и качества. См. [требования Unsloth](https://unsloth.ai/docs/get-started/fine-tuning-for-beginners/unsloth-requirements).

## Входные данные и критерий допуска

В обучение допускаются только реальные запросы/диалоги или сценарии действий,
прошедшие ручную проверку человеком. У каждой строки должны быть происхождение
сетевого измерения, SHA-256 снимка, время и экспертное обоснование метки.
Не добавлять
сгенерированные вопросы, ответы модели без редакторской проверки, имена,
пароли, личные данные, скрытые данные `.pt`, фиктивные вызовы инструментов или
автоматическую метку «ответ правильный».

Набор делится по независимым инцидентам, узлам и временным периодам на train,
validation и test. Снимки одного инцидента или близкие дубли не должны
пересекать эти части; тестовый набор не используется для настройки обучения.
Оценка должна включать точность решений и рекомендаций, долю утверждений,
подтверждённых измеренными полями телеметрии, корректность отказа при нехватке
данных, корректность инструментальных вызовов, latency и использование памяти.
До появления размеченного набора обучение не запускается и метрики не объявляются.

## Экспорт и подключение

После оценки кандидат отдельно экспортируется в GGUF, импортируется в Ollama
через `Modelfile` и `ollama create`, затем указывается в поле модели страницы
«ИИ-помощник». Текущий адаптер приложения принимает только локальный Ollama
server на loopback. Новая модель не заменяет штатный детектор IntegrityGuard.

Статус на 13 ноября 2026: инструментальная цепочка выбрана, hardware и runtime
проверены; Ollama установлена и интегрирована как локальная среда вывода.
Реальное дообучение не выполнялось: подтверждённого корпуса сетевых событий
с экспертной разметкой для помощника нет. Точность рекомендаций и
производительность на репрезентативных реальных сетевых задачах не подтверждены.
