# Ollama в сетевом мониторинге IntegrityGuard

## Назначение

Локальная Qwen анализирует текущую сетевую телеметрию и ограниченное read-only
состояние IntegrityGuard. На странице «Мониторинг» оценка запускается
автоматически примерно раз в минуту; оператор также может запросить оценку
вручную. Помощник не открывает пользовательские документы, не индексирует
каталоги и не отвечает по содержимому файлов.

## Данные и охват сенсора

Модель получает:

- счётчики входящих/исходящих байтов и пакетов сетевых интерфейсов;
- метаданные текущих TCP/UDP-соединений, агрегированные по удалённому IP;
- сводку очереди, доступных функций IntegrityGuard и последних безопасных
  полей журнала.

Это реальные данные ОС и приложения. PCAP и содержимое пакетов не собираются;
список соединений может не содержать кратковременные попытки и не гарантирует
полного обзора трафика. IP-адреса и счётчики передаются только локальному Ollama
по loopback.

## Политика решения

Ollama возвращает `ALLOW`, `REVIEW` или `BLOCK` и ID телеметрии, на которые
опирается. Если данных недостаточно, результат должен быть `REVIEW`. Пока нет
проверки на независимо размеченном реальном трафике, любой исходный `BLOCK`
принудительно преобразуется в итоговый `REVIEW`.

Вывод модели не создаёт правила Windows Firewall и не отбрасывает трафик.
Продукт пока не имеет подтверждённой оценки точности, ложных блокировок или
покрытия сенсора на целевой сети. Для перехода к enforcement нужны реальные
инциденты и чистый трафик с независимой разметкой, измеренные false-positive /
false-negative показатели, проверенное покрытие и обратимый контроллер правил
с allowlist и аудитом.

## Функции приложения и аудит

Помощник имеет фиксированный набор read-only функций: сетевой статус, статус
мониторинга, последние безопасные события и готовность бинарного детектора.
Каждая функция требует отдельной capability; произвольные пути и операции
изменения состояния не принимаются. Прямые вопросы вне этой области получают
сообщение о границах помощника и не запускают чтение файлов или вызов модели.

Запросы, ответы и результаты функций учитываются в локальном hash-chain аудите
через хеши; открытый текст телеметрии и сетевого ответа в него не записывается.
При недоступной Ollama оценка помечается как ошибка и не считается ни разрешением,
ни блокировкой.

## Runtime и обучение

- API Ollama: `http://127.0.0.1:11434`; удалённый адрес не допускается.
- Ollama и Qwen 3.5 4B Q4_K_M работают отдельно от IntegrityGuard; веса хранятся
  вне папки EXE (`F:\OllamaModels`).
- Дообучение Qwen на сетевых данных не выполнялось: подтверждённого корпуса нет.
- Qwen — advisory-слой анализа телеметрии, а не валидированный сетевой IDS и не
  замена пакетному `detector.pt`.

## Проверки и ограничения

Интеграционные проверки используют реальные счётчики ОС и таблицу соединений
этого компьютера. Автоматические тесты проверяют capability-границы,
валидацию аргументов, маршрутизацию сетевых запросов, границу no-file, журнал
аудита и downgrade решения `BLOCK`. Эти проверки подтверждают программный
маршрут, но не измеряют точность детектирования атак.
